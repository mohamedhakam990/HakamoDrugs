# Hakamo Drugs V6 🇪🇬💊

نسخة V6 من تطبيق Hakamo Drugs مع قاعدة أدوية مصرية كبيرة، الأسعار، الصيدليات القريبة، وواجهة AMOLED.

## المزايا

- قاعدة بيانات مصرية كبيرة يتم بناؤها تلقائيًا من Dataset حقيقي عند الـBuild.
- الاسم التجاري بالعربي والإنجليزي.
- الاسم العلمي والمادة الفعالة والشركة والشكل الدوائي والتصنيف.
- السعر بالجنيه المصري عند توفره في مصدر البيانات.
- البحث والتصنيفات والمواد الفعالة والمفضلة.
- تفاصيل الدواء مع المصدر وتاريخ التحديث.
- زر الصيدليات القريبة يفتح البحث الجغرافي في تطبيق الخرائط الموجود على الهاتف.
- رابط مباشر لقاعدة الأدوية المسجلة لدى هيئة الدواء المصرية.
- تحديث Online لقاعدة البيانات المصرية.
- قاعدة البيانات الأساسية داخل APK بعد نجاح GitHub Actions، لذلك البحث الأساسي يعمل Offline.
- AMOLED Dark Mode بخلفية سوداء حقيقية.
- صورة Showcase مولدة بالذكاء الاصطناعي.

## مصدر البيانات

يستخدم البناء Dataset مصريًا عامًا يحتوي على أكثر من 25 ألف سجل بحسب المصدر، ويُحوّل إلى SQLite قبل بناء APK.

المصدر الأساسي للبيانات:
https://github.com/karem505/egyptian-drug-database

للمراجعة الرسمية والبحث في المستحضرات المسجلة:
https://eservices.edaegypt.gov.eg/EDASearch/SearchRegDrugs.aspx

## مهم

السعر والتوافر قد يتغيران. وجود الصيدلية على الخريطة لا يعني أن الدواء متوفر لديها. المعلومات تعليمية وليست بديلًا عن النشرة الرسمية أو الطبيب/الصيدلي.

## Build من PowerShell

بعد رفع المشروع إلى GitHub، افتح Actions وشغل `Hakamo Drugs V6 Build`.

الـWorkflow يقوم تلقائيًا بـ:
1. تنزيل قاعدة الأدوية المصرية.
2. تحويلها إلى SQLite.
3. وضع SQLite داخل assets.
4. بناء APK.
5. رفع APK كـArtifact.

## ملاحظة عن الصيدليات

ميزة الصيدليات القريبة لا تحتاج API Key لأنها تفتح بحث الخرائط حول موقع المستخدم. إذا أردت قائمة صيدليات داخل التطبيق نفسه مع بيانات هاتف/ساعات/مسافة، يمكن ربط Google Places API لاحقًا مع API Key وقيود الاستخدام المناسبة.
